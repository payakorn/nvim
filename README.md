# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

See [KEYS.md](KEYS.md) for the keybinding reference — the bindings that differ
from stock LazyVim, and the LaTeX/Python tooling this config actually uses.
